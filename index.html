Прошивка пристрою ESP32

Ваш браузер не підтримується!

Будь ласка, відкрийте сторінку в Google Chrome, Microsoft Edge або Opera.

Увага: прошивка вимагає безпечного з'єднання (HTTPS)!

Запустіть сайт через HTTPS або локальний сервер (http://localhost).
  • Версія 3.6 — стабільна релізна версія прошивки для пристрою на ESP32.
  • Версія 3.6.1-b1 (Beta) — тестова версія із новими експериментальними функціями.

Якщо пристрій не відображається у списку портів:

  1. Переконайтеся, що USB-кабель підтримує передачу даних (а не тільки зарядку).
  2. Перевірте, чи горить індикатор живлення на вашій платі ESP32.
  3. Встановіть відповідні драйвери для USB-UART перетворювача:
    • Драйвер CP2102: Завантажити для Win/Mac
    • Драйвер CH340 / CH341: Завантажити для Windows
